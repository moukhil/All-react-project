## Getting Started

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/project-name.git
```

```bash
cd project-name
```

### Install Dependencies

```bash

```

### Start the Development Server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
